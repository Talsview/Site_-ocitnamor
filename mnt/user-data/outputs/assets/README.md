# assets/

Esta pasta está reservada para imagens, sons ou fontes locais que você queira
adicionar no futuro (por exemplo, uma foto do casal ou um efeito sonoro).

Ela está vazia por padrão: o visual atual do site (gradiente, corações,
emojis) é feito 100% em CSS/JS, sem precisar de nenhum arquivo aqui, então o
site carrega rápido e continua leve.

Se adicionar arquivos aqui, referencie-os com caminho relativo, por exemplo:

```html
<img src="assets/foto.jpg" alt="..." />
```
